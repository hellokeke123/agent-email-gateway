网关设置

设置对外公开地址后，授权页面链接、安装教程和下载的 Skill 包将使用同一个地址。

只允许绝对 HTTP/HTTPS URL；可包含代理路径前缀，不可包含凭据、查询参数或片段。

Worker webhook 安全例外

默认关闭。启用后，网关可以向受信任的本地或 RFC1918/IPv6 ULA 私有网络地址发起 HTTP 或 HTTPS 请求，仅用于本地测试或受控内部部署。公网 Worker 仍必须使用 HTTPS。

这不会允许公网 HTTP、重定向、元数据端点、链路本地、组播、保留地址或任意私有网络访问。Worker 仍必须验证 HMAC 签名；使用 HTTPS 时仍必须使用有效 TLS 证书。
